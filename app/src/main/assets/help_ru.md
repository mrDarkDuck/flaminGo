# Возможности FlaminGo

* **Проверка прокси:** Приложение проверяет доступность MTProto-прокси для Telegram.
* **Умное сито:** Сначала проверяются быстрые ссылки (1 сек), затем медленные (3 сек).
* **Только быстрые:** Фильтр отсекает прокси с пингом выше 150 мс для комфортной работы.
* **Свои списки:** Вы можете загрузить свой файл .txt со списком прокси.
* **Настройки:** Можно изменить ссылку на официальный список и глубину проверки.
* **Прямая отправка:** Кнопка ✈️ позволяет мгновенно добавить прокси в Telegram.
* **Разделение по сетям:** Списки сохраняются отдельно для каждого Wi-Fi и оператора.
* **Перепроверка (↻):** Кнопка со стрелочкой позволяет быстро перепроверить только уже найденные рабочие ссылки, не скачивая весь список заново.
