# Возможности FlaminGo

* **Проверка прокси:** Приложение проверяет доступность MTProto-прокси для Telegram.
* **Умное сито:** Сначала проверяются быстрые ссылки (1 сек), затем медленные (3 сек).
* **Только быстрые:** Фильтр отсекает прокси с пингом выше 150 мс.
* **Свои списки:** Вы можете загрузить свой файл .txt со списком прокси.
* **Настройки:** Изменение ссылки на список и глубины проверки.
* **Прямая отправка:** Кнопка ✈️ мгновенно добавляет прокси в Telegram.
* **Разделение по сетям:** Списки сохраняются отдельно для Wi-Fi и оператора.
* **Перепроверка (↻):** Быстрая перепроверка только уже найденных ссылок.

---
### ⚠️ Важная информация (Дисклеймер)
* **Доступность ссылок переменна:** Прокси может перестать работать в любой момент. Это зависит от оператора (ТСПУ/DPI), загрузки сервера и времени суток.
* **Принцип работы:** Приложение проверяет только TCP-соединение (открыт ли порт). Оно не гарантирует, что трафик Telegram пройдет через прокси *прямо сейчас*.

---
### 🔒 Конфиденциальность и Разрешения
Мы **не собираем, не храним и не передаем** никаких ваших личных данных. Все настройки и списки сохраняются только локально на вашем устройстве.
Приложение запрашивает следующие разрешения:
* **Геолокация / Поиск Wi-Fi:** Исключительно для того, чтобы Android позволил нам прочитать *имя* Wi-Fi сети (для разделения списков по сетям).
* **Данные телефона:** Только для чтения имени сотового оператора (МТС, Билайн и т.д.), чтобы сохранять списки отдельно для каждой SIM-карты.
* **Уведомления:** Для отображения прогресс-бара проверки в шторке.
*(Вы можете запретить доступ к геолокации и звонкам, приложение продолжит работать, но будет сохранять списки под общим именем «Wi-Fi» или «Mobile»).*
