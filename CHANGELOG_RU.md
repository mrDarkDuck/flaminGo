## Версия 2.0
* **Новый интерфейс:** Кнопка «Что нового» теперь появляется только при наличии непрочитанных обновлений.
* **Слайдер обновлений:** История обновлений теперь листается слайдами из настроек.
* **Справка:** Добавлен отдельный раздел с описанием возможностей приложения.
* **Улучшение поиска:** Опция «Только быстрые» теперь включена по умолчанию.
* **Активное сито:** Проверка идет в два этапа для максимальной скорости.
