# FlaminGo Features

* **Proxy Checking:** The app checks the availability of MTProto proxies for Telegram.
* **Active Sieve:** Fast links are checked first (1 sec), then slow ones (3 sec).
* **Fast Only:** A filter that cuts off proxies with ping above 150 ms for a smooth experience.
* **Custom Lists:** You can load your own .txt file with a proxy list.
* **Settings:** Change the official list URL and check depth (until 1, 3, or 5 working proxies).
* **Direct Send:** The ✈️ button instantly adds a proxy to Telegram.
* **Network Splitting:** Lists are saved separately for each Wi-Fi network and mobile carrier.
