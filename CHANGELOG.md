# История изменений FlaminGo

## Версия 1.9
* **Улучшение интерфейса:** Кнопка "Настройки" заменена на символ шестеренки (⚙️) и перенесена в левый верхний угол.
* **Улучшение интерфейса:** Кнопка "Что нового?" теперь выровнена по центру верхней панели.

## Версия 1.7
* **Косметика:** Номер версии перенесен в самый низ экрана (формат V1.7).
* **Косметика:** Кнопка "Перепроверить" заменена на компактный символ "↻".
* **Исправление верстки:** Исправлен баг, из-за которого при обновлении могла слетать верстка экрана.
* **Багфикс:** Исправлена ошибка, из-за которой прогресс-бар при запуске приложения оставался на позиции прошлой проверки.

## Версия 1.6
* **Косметика:** Номер версии перенесен в самый низ экрана (формат V1.6).
* **Косметика:** Кнопка "Перепроверить" заменена на компактный символ "↻".
* **Багфикс:** Исправлена ошибка, из-за которой прогресс-бар при запуске приложения оставался на позиции прошлой проверки.

## Версия 1.5
* **Автообновление:** Приложение теперь само проверяет обновления при запуске.
* **Кнопка "Обновить":** Появляется вверху экрана, если на GitHub есть версия новее.
* **Улучшения интерфейса:** Кнопка выхода теперь стандартная, добавлен раздел «Настройки».

## Версия 1.4
* **Настройки:** Добавлен раздел настроек (шестеренка/кнопка).
* **Редактирование URL:** Теперь можно менять ссылку на список МТПрото. Если стереть — вернется стандартная.
* **Глубина проверки:** Можно останавливать поиск после нахождения 1, 3 или 5 рабочих прокси.
* **Фильтр скорости:** Опция "Показывать только быстрые" (пинг < 150 мс).
* **ReCheck:** Новая кнопка для быстрой перепроверки ТОЛЬКО текущего списка рабочих ссылок.
* **Косметика:** Кнопка выхода теперь в едином стиле с остальными кнопками.
* В строке версии убрано время сборки, оставлен только номер версии. 

## Версия 1.3
* **Постоянная подпись:** Теперь приложение можно обновлять поверх старого без удаления (данные сохраняются).
* **Автообновление:** Добавлена кнопка "Обновить", которая проверяет новые версии на GitHub и скачивает их.
* **Автонумерация:** Каждая сборка автоматически получает новый номер версии.
* **Release-сборка:** Приложение собирается в оптимизированном формате Release.

## Версия 1.2
* **Исправлен баг с восстановлением экрана:** Если вы свернули приложение во время проверки, то при возвращении прогресс-бар и найденные ссылки подтягиваются из памяти сервиса.
* **Исправлена передача данных в Android 13+:** Сигналы между сервисом и интерфейсом теперь приходят корректно при любых настройках системы.

Примечание: При первом запуске обновленного приложения Android запросит разрешение на «Геолокацию» и «Телефон». Это нужно только для того, чтобы прочитать имя Wi-Fi сети и название оператора (современные версии Android требуют этого). Приложение не отслеживает ваше местоположение и не отправляет эти данные никуда, они нужны только для локального разделения списков.
