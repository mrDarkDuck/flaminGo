# История изменений FlaminGo

## Версия 1.0
* Добавлена дата и время последней проверки на главный экран.
* Рабочие прокси теперь сортируются по скорости (быстрые сверху).
* Пинг окрашивается в цвета: Зеленый (<150 мс), Желтый (<400 мс), Красный (>400 мс).
* Добавлено описание приложения на главный экран.
* Кнопка "Выход" перенесена наверх в виде крестика.
* Исправлен баг с сохранением списка при выходе из приложения.
* Добавлена кнопка "Что нового" с загрузкой этого файла.
* Исправлено время сборки (теперь по Москве).
