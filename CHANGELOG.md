# История изменений FlaminGo

## Версия 1.0
* **Умное сохранение:** Списки теперь сохраняются отдельно для каждой Wi-Fi сети (по имени) и каждого сотового оператора (например, МТС или Билайн).
* **Отображение сети:** На экране теперь пишется конкретное имя Wi-Fi сети или название оператора.
* **Живой мониторинг:** Приложение автоматически обновляет данные при переключении между сетями.
* Добавлена дата и время последней проверки на главный экран.
* Рабочие прокси сортируются по скорости (быстрые сверху).
* Пинг окрашивается в цвета: Зеленый (<150 мс), Желтый (<400 мс), Красный (>400 мс).
* Кнопка "Выход" перенесена наверх в виде крестика.
* Исправлен баг с дублированием списков при перезапуске.
* Добавлена кнопка "Что нового".


Примечание: При первом запуске обновленного приложения Android запросит разрешение на «Геолокацию» и «Телефон». Это нужно только для того, чтобы прочитать имя Wi-Fi сети и название оператора (современные версии Android требуют этого). Приложение не отслеживает ваше местоположение и не отправляет эти данные никуда, они нужны только для локального разделения списков.
